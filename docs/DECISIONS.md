# Architecture Decisions

| ADR | Decision | Status |
|---|---|---|
| `adr/0001-monorepo.md` | Use a polyglot monorepo | Accepted |
| `adr/0002-hosted-file-search.md` | Use hosted File Search behind a retrieval adapter | Accepted |
| `adr/0003-language-split.md` | Use TypeScript for browser applications and Python for services | Accepted |
| `adr/0004-dependency-tools.md` | Use pnpm and uv with committed lockfiles | Accepted |
| `adr/0005-control-plane-postgres.md` | Use PostgreSQL for control-plane and tenant data | Accepted |
| `adr/0006-repository-prompts.md` | Treat prompts and evaluations as versioned source assets | Accepted |
| `adr/0007-observability.md` | Use OpenTelemetry-compatible telemetry | Accepted |
| `adr/0008-widget-isolation.md` | Use a Web Component launcher and sandboxed iframe | Accepted |
| `adr/0009-tenant-isolation.md` | Enforce layered tenant isolation including PostgreSQL RLS | Accepted |
| `adr/0010-immutable-promotion.md` | Build once and promote immutable artifacts | Accepted |
