# Codex Workspace Guide

This repository contains **463 atomic tasks** across eight phases.

## Recommended Codex flow

1. Read `AGENTS.md`.
2. Read the selected task in `codex/tasks/tasks.json`.
3. Read the task's phase in `docs/PLAN.md`.
4. Inspect relevant architecture and engineering requirements.
5. Implement only the selected task.
6. Add tests and documentation.
7. Run available checks.
8. Return a structured completion report.

## Task files

- `tasks/tasks.json`: authoritative machine-readable backlog.
- `tasks/task-index.csv`: compact sortable index.
- `tasks/by-phase/`: one Markdown checklist per phase.
- `TASK_TEMPLATE.md`: issue or work-order template.
- `TASK_EXECUTION.md`: execution rules.
- `REVIEW_CHECKLIST.md`: reviewer checklist.
